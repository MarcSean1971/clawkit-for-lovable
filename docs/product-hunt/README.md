# Product Hunt Launch Kit

This folder contains the prepared Product Hunt launch materials for **ClawKit for Lovable**.

## One-Click Path

Run:

```powershell
.\scripts\launch-product-hunt.cmd
```

That opens the local launch cockpit and the Product Hunt submit page.

Product Hunt does not provide a reliable public one-click prefill URL for every field. The launch cockpit gives copy buttons for each field and links to the required pages so the manual Product Hunt submission is reduced to a few clicks.

## Product Hunt Fields

- Product name: `ClawKit for Lovable`
- URL: `https://clawhub.ai/plugins/%40clawkit%2Fclawkit-for-lovable`
- Tagline: `Turn Lovable apps into verified, live products`
- Pricing: `Free`
- Suggested tags: `AI Agents`, `Developer Tools`, `No-Code`
- Additional link: `https://github.com/MarcSean1971/clawkit-for-lovable`

## Upload Assets

Product Hunt currently asks for:

- Square thumbnail, recommended `240x240`, under 3MB.
- At least two gallery images, recommended `1270x760`.

Prepared PNGs:

- `assets/clawkit-ph-thumbnail.png`
- `assets/clawkit-ph-gallery-1.png`
- `assets/clawkit-ph-gallery-2.png`
- `assets/clawkit-ph-gallery-3.png`

SVG source files are kept beside them so the copy can be edited.

## Launch Notes

Product Hunt says makers can post their own product, and that a personal account is required. It also says to log in, click Submit/Post, choose New Product, then enter the product URL to start. Product Hunt's launch guide recommends a clear tagline, a concise description, two or more gallery images, and a first maker comment.

For launch timing, Product Hunt says the best time is when you are ready, but notes that `12:01am PT` gives the product the full 24-hour homepage cycle. You can schedule up to one month ahead.

## Final Checklist

- [ ] Product Hunt personal account is ready and onboarded.
- [ ] Maker profile has a real photo/name and short bio.
- [ ] ClawHub page loads and shows the latest version.
- [ ] GitHub repo is public and README is current.
- [ ] Thumbnail and gallery images uploaded.
- [ ] First maker comment pasted.
- [ ] Launch scheduled or launched.
- [ ] Launch URL copied into outreach posts.
- [ ] Respond to every comment with helpful detail, not upvote requests.
